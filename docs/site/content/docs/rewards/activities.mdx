福利活动的核心玩法是**消费抽奖**：你正常使用 Pixel API 产生消费，达到活动门槛后获得抽奖机会，参与抽奖就有机会中奖。

## 三步玩法

<Steps>
  <Step>**达标获得机会**：在活动统计周期内，你的 API 消费达到门槛，就获得抽奖机会。</Step>
  <Step>**手动参与抽奖**：获得机会后**需要手动点「参与抽奖」**，才会进入本期开奖池。不点不算参与。</Step>
  <Step>**等待开奖公示**：到开奖时间统一开奖并公示结果，中奖会记录在你的中奖记录里。</Step>
</Steps>

<Callout type="warn" title="机会要手动用掉">
  「获得抽奖机会」和「参与抽奖」是两步。获得机会后一定要点参与，且要在开奖时间之前参与；开奖时间一到就不能再参与了。
</Callout>

## 怎么算「达标」

达标口径是你的 **API 实际消耗**或 **API 请求次数**（看活动配置）。不同活动发放抽奖机会的方式也不同：

| 发放模式 | 含义 |
| --- | --- |
| 固定次数 | 达标即获得固定几次机会 |
| 按消耗递增 | 消耗越多，机会越多 |
| 阶梯次数 | 按消耗分档，达到不同档位给不同次数 |

统计周期可能是：当天 / 近 N 天 / 指定时间段 / 整个活动周期。活动卡上会显示门槛、统计周期、开奖时间、你的机会数和已参与人数。

## 奖品有哪些

| 奖品类型 | 说明 |
| --- | --- |
| 余额 | 直接到账余额 |
| 积分 | 到账积分 |
| 负载额度 | 到账负载额度 |
| 实物 / 人工奖品 | 需要你**填写领奖信息**，由人工发放 |

## 页面里的几个 Tab

| Tab | 内容 |
| --- | --- |
| 可参与 | 当前进行中、可以参与的活动 |
| 已参与 | 你已经参与的活动 |
| 中奖记录 | 你的历史中奖 |
| 往期 | 已结束的活动 |
| 邀请返利 | 邀请返利入口（同[邀请返利](/docs/rewards/affiliate)） |

## 中奖后要做什么

中奖记录会显示状态：

| 状态 | 含义 |
| --- | --- |
| 待填写信息 | 实物奖品需要你先填领奖信息 |
| 待发放 | 已登记，等待发放 |
| 已发放 | 奖励已到账 / 已寄出 |
| 已驳回 | 领奖信息或资格未通过 |
| 已过期 | 超时未领取，作废 |

实物奖品记得及时**填写领奖信息**并提交，否则可能过期。余额/积分/负载额度类奖品通常自动到账。

<Callout type="info" title="和商城抽卡不是一回事">
  福利活动的抽奖是**靠消费达标获得的免费机会**；发卡商城里的「余额/积分抽卡」是**花钱买的抽卡商品**。见[发卡商城](/docs/wallet/store)。
</Callout>
