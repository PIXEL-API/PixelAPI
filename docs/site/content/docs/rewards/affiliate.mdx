邀请返利让你通过分享 Pixel API 赚钱：把邀请码或邀请链接发给别人，对方注册并产生有效消费后，系统按比例把返利**实时打进你的余额**。

## 在哪里进

两个地方都是同一个功能：

- 独立的「邀请返利 / 邀请收益」页面。
- [福利活动](/docs/rewards/activities)页面里的「邀请返利」Tab。

## 你能看到和做什么

| 项目 | 说明 |
| --- | --- |
| 我的邀请码 / 邀请链接 | 复制后分享给别人 |
| 本周邀请码次数 | 邀请码的每周使用配额 |
| 邀请码策略 | 可选「每周一 00:00 自动换新码」或「保留当前码」 |
| 我的邀请分成 | 你的返利比例（以站点配置为准） |
| 邀请人数 / 已邀请用户 | 你邀请到的用户列表 |
| 邀请收益 | 今日 / 昨日 / 近 7 天 / 历史收益 |

## 返利怎么结算

- 被邀请用户**产生有效消费**后，返利按配置比例**实时入余额**。
- 具体返利比例**以站点当前配置为准**。
- 邀请返利属于余额收益，可以继续在站内消费，也可以按提现规则申请提现（见[计费与提现](/docs/billing)）。

<Callout type="info" title="邀请返利 vs 号主收益">
  邀请返利是「你拉来的人消费，你拿分成」；号主收益是「别人用你共享的账号，你拿收益」。两者都进余额，但来源不同。号主收益见[查看收益流水](/docs/owner-check-income)。
</Callout>
