---
title: 福利与邀请
description: 消费抽奖福利活动、邀请返利和优惠码的总入口。用日常消费和分享换更多余额、积分与奖品。
---

这里整理消费抽奖、邀请返利和优惠码三类福利入口。正常使用或分享 Pixel API 时，可以通过这些入口获得额外余额、积分、负载额度或奖品。

## 三个板块

<Cards>
  <Card title="福利活动" href="/docs/rewards/activities" description="消费达标获得抽奖机会，参与抽奖赢余额、积分、负载额度或实物奖品。" />
  <Card title="邀请返利" href="/docs/rewards/affiliate" description="用邀请码/链接拉新用户，对方有效消费后按比例实时返利到你的余额。" />
  <Card title="优惠码" href="/docs/rewards/coupons" description="充值或下单时输入优惠码抵扣或获得赠送。" />
</Cards>

<Callout type="info" title="奖励最终都进你的钱包">
  这里赢到的余额、积分、负载额度，都会进你的账户。想知道它们分别能干什么，见[余额与积分](/docs/wallet/balance)。
</Callout>

<Callout title="这些板块可能看不到">
  福利活动、邀请返利等可能因站点运行在「简易模式」或未开启对应功能而隐藏，以你控制台实际显示的菜单为准。
</Callout>
