优惠码用在**充值或下单**的时候，帮你抵扣金额或获得赠送余额。它不是独立到账的东西，而是配合一次付款使用。

## 怎么用

优惠码通常在这些场景出现（以站点配置为准）：

- **注册时**：部分站点在注册流程中使用优惠码，获得赠送余额。
- **充值 / 下单时**：在支付页面填入优惠码，享受抵扣或赠送。

按页面提示在对应的输入框填入优惠码即可，页面会显示优惠后的金额。

<Callout title="优惠码 ≠ 兑换码 ≠ 发卡商城">
  三个最容易混，一张表看懂：

  | 名称 | 怎么用 | 结果 |
  | --- | --- | --- |
  | 优惠码 | 充值/下单时填入 | 抵扣金额或赠送 |
  | [兑换码](/docs/wallet/redeem) | 在「兑换」页单独输入 | 直接到账余额/积分/并发/订阅 |
  | [发卡商城](/docs/wallet/store) | 花钱购买商品 | 交付卡密内容 |
</Callout>
