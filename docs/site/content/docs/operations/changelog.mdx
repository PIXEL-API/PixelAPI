## v1.2.54

- 「有个想法」板块新增系统开关：管理员可在系统设置中启用或停用该板块，关闭后前端隐藏入口、后端接口返回不可用提示；首次上线默认开启。

## v1.2.53

- 新增「有个想法」经验分享板块：用户可发布与编辑经验文章、查看版本留痕、点赞、收藏、按标签浏览，也可对内容进行举报；管理员可在后台对文章、举报、标签进行审核与处置。
- 接入 AI 内容审核：文章发布或修订前自动过审，记录模型快照、风险等级、审核理由与重试状态，审核失败进入相应状态并在需要时人工复核。
- 支持对文章打赏：余额与积分两种资产，带幂等键防重复扣款，流水复用既有余额/积分账本；附件转私有 OSS 存储并记录审计事件。
- 模型目录统一改造（Sprint 1/2）：账号测试连接、模型白名单、渠道定价与调度校验统一到同一份模型目录口径，管理员端与用户端模型候选一致，避免把已下架模型写入白名单。
- 新增数据库迁移 279_ideas_plaza（已应用）：创建 `idea_*` 系列 12 张业务表，均为幂等 DDL，不改动既有余额/账本表结构。

## v1.2.52

- 共享号池瞬时 429 不再拆散房间绑定：30 秒内可自愈的限流只返回可重试错误并保留活跃席位，只有超过完整宽限窗口且确有健康账号可替换时才真正重排队，避免高峰期用户被频繁踢出房间。
- 账号限流时间只延长不回退：连续 429 时保留本轮首次触发时间并只向后延长重置时刻，较旧的上游响应不会缩短冷却，修正短时限流判定的时间基准。
- 房间请求错误语义细分：账号恢复中返回 503 并带 `Retry-After`，空闲超时返回 409 并提示重新加入房间，不再统一报「账号未绑定」；错误响应只携带重试秒数，不再暴露账号 ID、席位 ID 等内部信息。
- 管理员修改在用账号新增版本校验：二次确认时会带上房间席位的版本快照，若确认期间房间状态发生变化则明确提示需刷新后重新确认，避免基于过期快照的强制修改。
- 新建与编辑账号的模型白名单候选改为从渠道定价目录实时加载，管理员端与用户端口径一致，并补充加载中/加载失败/目录为空三种状态提示；粘贴凭证类入口在提交前会等待最新目录就绪，避免把已下架模型写入白名单。

## v1.2.51

- OpenAI「Free」共享号池调整为通用基础池：接受并调度同平台任意等级以及未识别等级的账号，避免等级探测失败的账号无池可用；其他等级池仍按等级精确匹配，Grok 保持 Free/Heavy 严格匹配不变。
- 个人账号模型白名单改为严格口径：新建与凭证文件导入的个人账号必须落到服务端当前定价目录内的精确模型集合，导入流程在没有模型选择步骤时按当前活跃渠道定价并集生成同名白名单，不再回退平台预置模型全集。
- 用户端账号「测试连接」可选模型列表严格遵守号主白名单，白名单为空时返回空集合，与调度校验口径保持一致。
- 修复 OAuth 授权码可被重复兑换的问题：兑换成功后立即清理授权码输入与会话，账号创建失败时需重新生成授权链接，避免同一个一次性 code 二次提交给上游导致 502。
- 账号创建/导入弹窗在兑换授权码前重新拉取服务端模型目录并校验，明确提示已失效模型而不是静默裁剪用户的选择；OAuth 失败提示改用统一的接口错误解析，不再因错误对象结构不符而显示空白原因。

## v1.2.50

- 新增 OpenCode 账号模式：账号广场可对 OpenCode（仅 API Key）账号建立共享房间，房间模型白名单自动对齐 OPENCODE 渠道已定价的模型，避免上架未定价模型导致计费为 0；OpenCode 房间的健康探测改用稳定默认模型，减少因首个白名单模型不可用而误判账号失效。
- Gemini（Google 官方 API）生图输出计费：按上游实际回吐的内联图片数量计入用量，同一份响应取最大值而非逐分片累加，避免 Gemini 累积式流式分片导致的重复计费。
- 限制 /models 模型列表响应的读取大小，防止异常超大响应被完整读入占用资源。
- 渠道中心支持按平台聚合已定价模型列表，用于账号模式房间白名单兜底。

## v1.2.48

- 429 无法解析上游重置时间时，默认回避时长由 5 分钟改为可配置的秒级默认（默认 5 秒），可在系统设置中运行时调整或关闭，避免并发/RPM 类瞬时 429 的账号被误伤到长时间不可调度。
- 修复 Anthropic /messages 计费归一化：国产模型返回 Anthropic 语义的 input_tokens（不含缓存）时折叠缓存计入用量，避免多轮会话少计费；OpenAI 语义（已含缓存）不重复计数。
- 「测试连接」流程的可选模型列表逻辑抽取为管理员端与用户端共用，避免两端口径不一致。
- 工单超时自动回复时间由 12 小时缩短为 4 小时。

## v1.2.47

- 修复渠道定价开启「限制模型」后用户仍可调用定价之外模型的问题，覆盖所有平台的调度选择与逐账号校验路径。
- ChatGPT（OpenAI OAuth）账号对套餐未开通的模型返回 400 时按「账号 + 模型」维度冷却 30 分钟，避免反复重试同一失败账号；图片模型误发到文本端点被拒时不再写入冷却，避免误伤正常生图请求。
- 新增 OpenAI APIKey 账号的 /v1/responses 能力探测：账号创建/更新后异步探测上游是否支持带工具调用并持久化结果，避免长期误走 chat/completions 导致 Codex 提示缓存命中率下降。
- 修复 OpenCode 账号校验模型因区域限制被误判为「待校验」的问题，校验失败时自动回退到其他可用模型。
- 修复个人账号批量更新时删除模型后报「No updates provided」的问题。
