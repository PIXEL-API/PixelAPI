发卡商城（也叫自助发卡商城）是一个站内的数字商品自助商店。你可以用余额、积分或平台支付购买商品，付款完成后系统**自动交付**，无需人工发货。

## 商城里有哪些商品

| 商品类型 | 是什么 | 交付内容 |
| --- | --- | --- |
| 卡密（`card_key`） | 经典的卡密商品 | 交付一段**卡密内容**：文本码或可下载文件 |
| 余额抽卡（`balance_draw`） | 抽卡式购买，随机返还一笔余额 | 在「随机返还区间」内随机到账余额 |
| 积分抽卡（`points_draw`） | 抽卡式购买，随机返还一笔积分 | 在「随机返还区间」内随机到账积分 |
| 负载额度（`load_factor_credits`） | 购买负载额度 | 按数量到账**负载额度** |

<Callout type="info" title="抽卡是随机返还">
  余额/积分抽卡是「随机返还区间」内的随机结果，不是固定数值，页面会显示区间和本周期进度。它和[福利活动的消费抽奖](/docs/rewards/activities)不是一回事：这里是**花钱买的抽卡商品**，福利活动是**靠消费达标获得的免费抽奖机会**。
</Callout>

## 支付方式

每个商品可单独允许下面几种支付方式（以商品页显示为准）：

| 支付方式 | 说明 |
| --- | --- |
| 余额支付 | 用账户余额购买，余额不足会提示 |
| 积分支付 | 用账户积分购买 |
| 平台支付 | 走支付宝、微信或 Stripe 等在线支付，和[充值](/docs/wallet/purchase)是同一套支付流程 |

## 购买流程

<Steps>
  <Step>在商城浏览商品，可按分类筛选，查看单价、库存和说明。</Step>
  <Step>点击「购买」，在弹窗里选择购买数量和支付方式，核对「单价 / 合计」。</Step>
  <Step>点击「确认购买」。余额/积分支付即时完成；平台支付会走扫码/跳转付款流程。</Step>
  <Step>付款完成后自动交付：卡密会显示「已发放卡密」并可复制，文件可下载。</Step>
  <Step>之后随时能在[订单与发票](/docs/wallet/orders)里再次查看已购卡密或下载文件。</Step>
</Steps>

<Callout title="发卡商城 ≠ 兑换码">
  发卡商城**交付**给你的是卡密内容（一段码或文件）。如果这段码是充值类卡密，你还需要拿它去[兑换码](/docs/wallet/redeem)页面输入，才能把它变成账户里的余额/积分/并发/订阅。两个页面各管一头。
</Callout>
