充值把你付的钱变成账户里的**余额**，之后就能用于请求计费、发卡商城购物等。订阅则是另一种计费方式，按周期给你额度或权限。两者入口都在控制台的「充值/订阅」页面。

## 页面有三个 Tab

进入「充值/订阅」后，顶部最多有三个 Tab，具体显示哪些由站点配置决定：

<Tabs items={["充值中心", "充值", "订阅"]}>
  <Tab value="充值中心">
    列出站点整理的**外部充值入口**，每条有名称、说明和一个「前往」按钮。它不是站内付款，而是跳转到站点指定的外部地址。按站点指引操作即可。
  </Tab>
  <Tab value="充值">
    真正的**余额充值**表单：填金额、选支付方式、付款到账。下面几节主要讲这个 Tab。
  </Tab>
  <Tab value="订阅">
    购买**订阅套餐**。订阅按周期提供额度或权限，和一次性充值余额是两回事。订阅的额度与消耗见[我的订阅](/docs/wallet/balance)与[计费与提现](/docs/billing)。
  </Tab>
</Tabs>

## 充值金额怎么填

充值金额是**自由输入**的，没有固定的「充 100 送 20」这类套餐档位。

| 项目 | 说明 |
| --- | --- |
| 快捷金额 | 页面提供 `5 / 10 / 20 / 30 / 50 / 100` 几个常用金额，点一下即可填入 |
| 自定义金额 | 也可以手动输入任意金额 |
| 金额范围 | 受「单次充值金额 最小 - 最大」限制，以页面显示为准 |

<Callout title="第一次先小额">
  第一次充值建议先充最小额度，确认到账和自己的真实消耗，再决定是否加大。
</Callout>

## 手续费与到账倍率

付款金额和最终到账余额**可能不一样**，取决于站点是否配置了手续费和到账倍率。以下数值均**以站点当前配置为准**，页面会实时算给你看：

| 概念 | 含义 | 页面显示 |
| --- | --- | --- |
| 支付金额 | 你选的充值金额 | 「支付金额」 |
| 手续费 | 按比例附加在支付金额之上（可能为 0） | 「手续费」 |
| 实付金额 | 你实际要付的钱 = 支付金额 + 手续费 | 「实付金额」 |
| 到账倍率 | 人民币换算成余额的比例，例如 `1 CNY = x USD` | 「当前倍率」 |
| 到账余额 | 换算后真正进账户的余额 | 「到账余额」 |

付款前，请以页面汇总的「实付金额」和「到账余额」为准。

<Callout title="金额多出 0.01 / 0.02 是正常的">
  多名用户同时提交相同金额的订单时，系统会用极小的金额差异来区分订单。按页面显示的金额支付即可，会按显示金额到账。
</Callout>

## 支付方式

具体可用的支付方式由站点开启的支付渠道决定，常见有：

| 支付方式 | 说明 |
| --- | --- |
| 易支付 | 聚合支付入口 |
| 支付宝 | 含扫码、直连、App 唤起等形态 |
| 微信支付 | 含扫码、公众号/JSAPI 等形态 |
| Stripe | 银行卡 / Link 等 |
| Airwallex | 银行卡等 |

<Callout type="info" title="移动端支付失败会自动回落扫码">
  在手机上用微信/支付宝支付时，如果商户未开通对应的移动支付能力，系统会自动切换为扫码支付，按提示扫码即可。
</Callout>

## 充值到账的流程

<Steps>
  <Step>在「充值」Tab 填写或选择金额。</Step>
  <Step>选择支付方式，核对「实付金额」和「到账余额」。</Step>
  <Step>点击「确认支付」，按弹出的二维码 / 跳转页面 / 收银台完成付款。</Step>
  <Step>页面会显示「剩余支付时间」并自动轮询订单状态；付款成功后余额自动刷新。</Step>
  <Step>如果中途中断，可回到页面或「我的订单」继续处理，通常能恢复未完成的支付。</Step>
</Steps>

<Callout type="warn" title="没到账先别重复付款">
  付款后到账偶有延迟。先到[订单与发票](/docs/wallet/orders)看订单状态，确认订单是否已支付，不要盲目重复付款。
</Callout>
