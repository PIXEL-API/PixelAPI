「我的订单」集中管理你的充值订单和发卡商城订单。发票管理则用于为订单开具发票。

## 订单状态

订单会经历下面这些状态（以页面显示为准）：

| 状态 | 含义 |
| --- | --- |
| 待支付 | 已下单，等待付款 |
| 已支付 | 付款已确认 |
| 充值中 | 到账处理中 |
| 已完成 | 已到账 / 已交付 |
| 已过期 | 超时未付款，订单作废 |
| 已取消 | 你主动取消了订单 |
| 失败 | 支付或处理失败 |
| 退款相关 | 退款申请中 / 已退款等 |

## 你能做什么

<Steps>
  <Step>**查看订单**：按类型和时间查看所有充值、购物订单。</Step>
  <Step>**取消订单**：待支付订单可以取消。</Step>
  <Step>**查看卡密**：发卡商城订单可再次查看已交付的卡密内容或下载文件。</Step>
  <Step>**申请退款**：符合条件的订单可提交退款申请，需填写退款原因。</Step>
</Steps>

<Callout type="info" title="退款要看支付渠道">
  能否退款、退给哪个渠道，取决于订单使用的支付方式。页面会显示可退款的渠道范围，不满足条件时不会出现退款入口。
</Callout>

## 发票

如果站点开启了发票功能，可以在「发票管理」为订单申请开票。

<Callout title="发票入口可能看不到">
  发票管理是一个功能开关。如果你的控制台里没有「发票管理」菜单，说明站点没有开启这个功能，属于正常现象。
</Callout>
