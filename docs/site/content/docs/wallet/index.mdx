这里集中放所有和余额、订阅、订单、兑换码相关的操作。你可以先分清充值、发卡商城和兑换码三个入口，再根据自己的目标进入对应页面。

<Callout title="先分清三个入口">
  很多新用户会混淆这三样，先记住区别：

  - **充值**：用支付宝/微信等付款，把余额充进账户。见[充值与订阅](/docs/wallet/purchase)。
  - **发卡商城**：花余额/积分/在线支付，买卡密、抽卡或负载额度等数字商品。见[发卡商城](/docs/wallet/store)。
  - **兑换码**：把一串已经拿到的码输进去，直接到账余额/积分/并发/订阅。见[兑换码](/docs/wallet/redeem)。
</Callout>

## 这些板块可能看不到

Pixel API 的部分功能由站点管理员按需开启。如果你的控制台里**看不到发卡商城、充值、订单、发票**等入口，通常是：

- 站点运行在「简易模式」，隐藏了这些板块。
- 站点没有开启内置支付或对应功能开关。

这属于正常现象，以你控制台实际显示的菜单为准。
