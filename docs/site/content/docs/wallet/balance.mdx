Pixel API 里有几种「资产」，名字相近但用途不同。这一页帮你一次分清。

## 四种资产速查

| 资产 | 是什么 | 主要用途 |
| --- | --- | --- |
| 余额 | 账户里的钱（可能按站点倍率以 USD 计） | 请求计费、发卡商城购物、账号广场小时费等 |
| 积分 | 站内的另一种可消费点数 | 发卡商城积分支付、兑换/活动奖励等 |
| 并发数 | 你能同时发起的请求数上限 | 决定并发能力，可通过兑换码等提升 |
| 负载额度 | 一种额度型资产 | 由商城「负载额度」商品或活动奖品发放 |

## 它们从哪来

| 来源 | 可能到账 |
| --- | --- |
| [充值](/docs/wallet/purchase) | 余额 |
| [发卡商城](/docs/wallet/store) | 卡密、抽卡返还的余额/积分、负载额度 |
| [兑换码](/docs/wallet/redeem) | 余额 / 积分 / 并发数 / 订阅 |
| [福利活动](/docs/rewards/activities) | 余额 / 积分 / 负载额度 / 实物 |
| [邀请返利](/docs/rewards/affiliate) | 余额（被邀请人有效消费后实时入账） |
| 号主共享收益 | 余额（其他用户使用你的共享账号） |

## 余额还承载收益

如果你是号主，余额还会收到共享账号收益、账号模式收益、邀请分成等。这些收益可以留在站内继续消费，也可以按规则申请提现。

- 收益怎么产生、去哪里看：见[号主：收益和提现](/docs/owner-income)。
- 完整的计费与提现规则（倍率、小时费、收益分成、提现门槛）：见[计费与提现](/docs/billing)。
- 逐条资金明细（余额流水）：在[使用记录](/docs/usage)里查看。

<Callout type="info" title="订阅是另一回事">
  订阅按周期给你额度或权限，和余额、积分是不同的计费方式。订阅的额度与消耗以控制台「我的订阅」显示为准，规则见[计费与提现](/docs/billing)。
</Callout>
