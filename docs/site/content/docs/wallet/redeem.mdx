兑换码是一串码，输进控制台的「兑换」页面后，直接给你的账户加东西。码可能来自活动、客服、发卡商城购买的卡密等。

## 兑换码能换什么

一个兑换码会对应下面某一种奖励（以码本身的配置为准）：

| 奖励类型 | 到账内容 |
| --- | --- |
| 余额 | 增加账户余额 |
| 积分 | 增加账户积分 |
| 并发数 | 提高你的并发上限 |
| 订阅 | 发放一个订阅分组，有效期若干天 |

余额、积分、并发数都是**即时更新**的。

## 兑换规则

- 每个兑换码**只能使用一次**。
- 兑换码**区分大小写**，请原样输入，不要改动。
- 如遇兑换问题，请联系站点客服或[提交工单](/docs/operations/faq)。

## 兑换流程

<Steps>
  <Step>进入控制台「兑换」页面，页面顶部会显示你当前的余额、积分和并发数。</Step>
  <Step>在输入框粘贴兑换码，注意大小写。</Step>
  <Step>点击「兑换」。成功会提示「兑换成功」，对应额度即时更新。</Step>
  <Step>在「最近活动」记录里能看到本次兑换的类型和结果。</Step>
</Steps>

<Callout title="兑换码 ≠ 发卡商城 ≠ 优惠码">
  三者容易混：

  - **兑换码**（本页）：一码换到账余额/积分/并发/订阅。
  - **发卡商城**：花钱**买**商品，交付卡密内容。见[发卡商城](/docs/wallet/store)。
  - **优惠码**：充值或下单时**抵扣/赠送**，不是独立到账。见[优惠码](/docs/rewards/coupons)。
</Callout>

## 常见失败原因

| 提示 | 处理 |
| --- | --- |
| 兑换码无效 | 检查是否输错、含多余空格、大小写不对 |
| 兑换码已使用 | 一码只能用一次，无法重复兑换 |
| 兑换失败 | 记录码和时间，联系客服或提交工单 |
