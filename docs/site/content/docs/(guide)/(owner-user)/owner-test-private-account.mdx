---
title: 测试私有自用
description: 用私有分组 API Key 给自己发一条请求，确认账号真的能被调用；私有不通就不要往公共共享走。
---

先确认账号能给你自己用。**私有都不通，公共模式和账号广场更不用开。**

私有模式最容易排查：只有你一个人用，不涉及别人排队、收益结算、房间价格参数和公共校验。出问题就是账号本身或 Key 配置的事。

## 先看账号状态

进「我的账号」找到刚加的账号，确认五项：状态正常、错误信息为空、可调度已开启、Token 或授权有效、代理 IP 正常。

页面显示异常就先按提示处理——重新授权、换代理，或者降低并发。

## 创建私有分组 Key

进「API 密钥」→「创建 API 密钥」，名称填 `我的私有账号测试 Key`，分组选私有分组（或与你账号对应的那个私有分组）。

**多分组路由、IP 限制、额度和速率限制第一次全部不要开。**

没有私有分组可选，说明站点还没给你开放私有分组模板或权限，需要联系管理员。

## 发一条测试请求

打开 [ChatCompletions 格式](/docs/api/chat-completions)，填入控制台显示的 Base URL、刚创建的私有 Key、账号支持的模型，消息填：

```text
你好，请只回复：私有账号已连接
```

点 `Send`。

## 回使用记录确认

进「使用记录」，确认这条请求的 API Key 是私有测试 Key、模型是你填的那个、状态成功、有合理费用，并且能关联到你的账号或请求路径符合私有分组。

请求没进使用记录，先查 Base URL；有失败记录，按错误信息处理。

## 失败的四种常见情况

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 401 | Key 复制不完整或填错 | 用复制按钮重新复制 |
| 403 | Key 绑的不是私有分组，或没有该分组权限 | 检查 Key 的分组 |
| 模型不可用 | 模型不在账号支持范围内 | 从可用渠道或账号信息里复制模型名 |
| 上游授权失败 | Token 过期，或当时授权到了别的账号 | 重新授权 |
| 代理异常 | 代理不可用或容量满了 | 换代理 |

账号能稳定调用、错误率和代理状态都正常，就可以往下走了。
