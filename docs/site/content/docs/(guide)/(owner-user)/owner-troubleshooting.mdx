遇到问题时，不要一上来批量重导账号或乱改参数。先判断问题发生在哪一层。

号主链路可以拆成：

```text
上游账号 -> 授权/代理 -> 我的账号 -> 私有测试 -> 公共共享/账号广场 -> 用户请求 -> 收益流水 -> 提现
```

## 快速检查清单

先检查这 10 项：

1. 账号平台是否选对。
2. 账号等级是否选对。
3. 凭证类型是否被前台个人导入支持。
4. Token 或授权是否过期。
5. 代理 IP 是否可用。
6. 账号状态是否正常。
7. 私有模式是否测试成功。
8. 公共共享是否通过校验。
9. 账号广场参数是否过高或模型白名单错误。
10. 收益是否已经进入余额流水。

## 添加账号失败

常见原因：

- 平台选错。
- 凭证不是官方 OAuth 相关凭证。
- 文件里包含 API Key、URL、Cookie、Upstream 等字段。
- OpenAI 账号等级选错。
- Pro 账号没有使用代理登录导入。

处理：

1. 先只导入一个账号。
2. 确认平台和凭证匹配。
3. 删除不支持字段。
4. 按真实等级选择。
5. 需要代理时先配置代理。

## 授权后状态异常

常见原因：

- 授权错账号。
- Token 过期。
- 代理不可用。
- 上游账号本身异常。
- 并发设置过高。

处理：

1. 重新授权。
2. 换稳定代理。
3. 降低并发。
4. 检查账号等级和订阅状态。
5. 看账号详情里的错误提示。

## 私有测试不通

常见原因：

- 没有私有分组。
- API Key 没绑定私有分组。
- 模型名不支持。
- Base URL 填错。
- 账号不可调度。

处理：

1. 先看使用记录有没有请求。
2. 没有请求就查 Base URL 和 API Key。
3. 有失败请求就按错误码处理。
4. 没有私有分组时联系管理员开放。

## 公共共享不通过

常见原因：

- 账号状态不稳定。
- 公共共享校验失败。
- 代理异常。
- 等级选择错误。
- Token 刷新失败。

处理：

1. 回到私有模式测试。
2. 修复授权或代理。
3. 降低并发。
4. 点击重新校验。
5. 通过后再观察共享状态。

## 账号广场没人用

常见原因：

- 倍率太高。
- 小时费太高。
- 最低余额太高。
- 模型不吸引人。
- 账号经常满员或不可用。

处理：

1. 从普通用户视角看账号卡片。
2. 对比同平台账号。
3. 先降低一个关键门槛。
4. 保留常用模型。
5. 观察 1 到 2 天，不要频繁乱改。

## 有请求但没收益

常见原因：

- 请求失败。
- 是你自己在使用自己的账号。
- 不是收益场景。
- 余额流水筛选范围不对。
- 结算还没完成。

处理：

1. 看请求是否成功。
2. 切到余额流水。
3. 筛选共享账号收益或账号模式收益。
4. 扩大时间范围。
5. 仍没有时记录请求 ID 联系管理员。

## 提现失败

常见原因：

- 未保存收款码。
- 金额低于 1.00。
- 小数位超过两位。
- 余额不足以覆盖手续费。
- 已有待结算提现。

处理：

1. 保存收款码。
2. 检查余额。
3. 调整金额。
4. 等当前提现处理完成或取消。

## 找管理员时提供什么

不要发完整凭证。请提供：

1. 大概发生时间。
2. 账号名称。
3. 平台和账号等级。
4. 当前模式：私有、公共或账号模式。
5. 错误截图或错误文字。
6. 使用记录请求 ID。
7. 余额流水记录类型。

不要发送完整 API Key、OAuth JSON、Refresh Token、Session Key、Cookie 或完整收款码截图。
