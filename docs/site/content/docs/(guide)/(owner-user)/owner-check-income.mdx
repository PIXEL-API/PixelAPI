**加了账号、过了校验、建了房间，都不等于已经赚钱。** 收益只看余额流水。

## 收益有四个来源

| 来源 | 什么情况下产生 | 余额流水里显示 |
| --- | --- | --- |
| 公共共享 | 普通用户通过共享号池自动调用你的账号 | 共享账号收益 |
| 账号广场 | 用户主动加入你的账号模式房间 | 账号模式收益 |
| 邀请分成 | 你邀请的用户产生有效消费 | 邀请分成收益 |
| 专属分组 | 站点配置的专属分组佣金 | 专属分组佣金 |

## 先看有没有人在用

进「使用记录」，时间范围放今天或最近 24 小时，能筛账号就选你的上游账号，状态先看全部。

重点确认：有没有其他用户的请求、请求成功没、模型在不在你的白名单里、有没有集中的失败状态码。

## 再看钱到没到

在「使用记录」里切到「余额流水」。

<Screenshot src="/images/guide/real-balance-ledger.webp" alt="Pixel API 使用记录页面余额流水截图，展示请求记录和余额流水切换、API 密钥筛选、时间范围、刷新和导出 CSV">
  <strong>收益到没到以这里为准：</strong>切到余额流水，筛共享账号收益、账号模式收益、小时费预扣和小时费退回。
</Screenshot>

可以筛的流水类型一共七种：共享账号收益、账号模式收益、邀请分成收益、专属分组佣金，以及账号模式小时费的预扣、退回和达标退回。

前四种是**你的收入**；后三种是用户侧的占位费用，会先预扣、低消达标后再退给用户。账号广场里请求费用和小时费是两套独立逻辑，不要混着看。

完整的计费口径、分成策略和倍率规则见[计费与提现](/docs/billing)。

## 一分钱没有？按这个顺序查

1. 有没有其他用户使用过你的账号。
2. 那些请求成功了吗（**只有失败请求通常不产生有效收益**）。
3. 是不是你自己在用自己的房间（自用不算号主收益）。
4. 账号确实处于公共模式或账号模式吗。
5. 余额流水的时间范围是不是太窄了。
6. 是不是还没完成结算。

## 收益低，先分清是哪类问题

| 现象 | 可能原因 |
| --- | --- |
| 没人加入你的房间 | 倍率高、小时费高、模型不吸引人、最低余额门槛高 |
| 加入后很快退出 | 小时费不合适、模型请求失败、空闲退出设太短 |
| 请求很多但失败也多 | 账号不稳、代理异常、并发过高、模型白名单配错 |
| 公共模式一直没收益 | 账号没通过公共校验，或没被共享号池调度到 |

**不要凭感觉调参。** 先看数据，然后一次只改一个参数，观察一两天再动下一个——同时改三个你永远不知道是哪个起了作用。
