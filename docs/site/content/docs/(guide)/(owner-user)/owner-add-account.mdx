第一次加账号看[添加第一个账号](/docs/owner-create-first-account)——一个一个加，跑通再说。**这一页是你已经熟悉流程、要批量导入或配代理时的参考。**

## OpenAI 等级的硬限制

导入 OpenAI 账号时要选等级，各等级的限制不一样：

| 等级 | 怎么导 | 注意 |
| --- | --- | --- |
| Free | JSON 或 Refresh Token | 无法确认等级时按 Free 处理 |
| Plus | JSON 或 Refresh Token | 只接受真的 Plus 账号 |
| Pro | **必须账号登录导入，并选代理 IP** | 不能贴凭证 |
| Team | JSON 或 Refresh Token | 只接受真的 Team 账号 |

**不要为了拿高额度随便选高等级。** 最终以实际校验为准，选错只会校验失败。

## 代理 IP

代理 IP 是平台代表你的账号去完成登录、兑换授权码或维持会话时用的网络出口。

四种情况需要配：OpenAI Pro 通过账号登录导入；页面明确提示要选代理；账号对登录地区或网络环境敏感；你希望账号长期用固定出口。

新增代理时可以用「智能识别」，粘这两种格式都认：

```text
192.168.0.1:8000:用户名:密码
用户名:密码@192.168.0.1:8000
```

手动填的话字段是：代理名称（只给你自己认，例如 `Roxy 独立 IP`）、协议（socks5 / http / https）、主机、端口（1–65535）、用户名和密码（代理服务商给的）。

提示"该代理 IP 已达到账号容量上限"就是这个代理满了，换一个。

## 能导入什么，不能导入什么

个人导入**只会创建官方 OAuth 账号**。各平台接受的格式：

| 平台 | 接受的凭证 |
| --- | --- |
| OpenAI | Sub2API OAuth JSON、Codex-Manager ChatGPT Token JSON、OpenAI Refresh Token |
| Claude | Sub2API OAuth JSON、Claude Session Key |
| Gemini | 带 `platform: gemini` 的官方 OAuth JSON |
| Antigravity | 带 `platform: antigravity` 的官方 OAuth JSON |

**一律会被拒绝**：API Key、URL、Upstream、Cookie，以及任何不属于官方 OAuth 的凭证字段。文件里混了这些，失败明细会提示"个人账号不允许导入该凭证字段"。

导入前必须先选对「导入平台」：ChatGPT / Codex 选 OpenAI，Claude 官方账号选 Anthropic，Gemini 和 Antigravity 各选自己。**Gemini 和 Antigravity 只吃带对应平台信息的 OAuth JSON，普通 Token 不行。**

## 两种导入方式

**批量文本**——适合手里只有 Token 或想直接贴 JSON。粘贴区支持每行一个普通 Token，也支持完整 JSON 或 JSON 数组：

```json
[
  {
    "platform": "openai",
    "type": "oauth"
  }
]
```

上面只是结构示意，实际字段以你导出的凭证文件为准，**不要照抄当真实凭证**。

**文件 / 目录**——支持 `.json`、`.txt`、多文件和整个目录，适合一次导很多。

导入完成后页面会给出：创建了几个、跳过几个、失败几个，以及每个失败账号的原因。批量导入常见部分成功部分失败，逐条看失败明细就行。

## 导完之后

回「我的账号」列表核对：名称出现了、平台和类型正确、共享模式是你选的、状态正常、错误信息为空、可调度已开启、今日统计能刷新。公共模式的话再看共享状态是通过还是正在校验。

**状态异常就先处理这一个，不要接着导更多。**

想验证账号能不能用，走[测试私有自用](/docs/owner-test-private-account)；准备共享出去，走[开启公共共享](/docs/owner-public-share)。
