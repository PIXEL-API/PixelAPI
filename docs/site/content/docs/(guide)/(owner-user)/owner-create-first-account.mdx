这一步的目标是：把第一个上游账号添加到 Pixel API，并在“我的账号”列表里看到它。

如果你已经有批量凭证，也建议先只导入一个账号。一个账号跑通以后，再批量导入。

## 第 1 步：进入我的账号

登录 Pixel API 控制台，进入左侧菜单「我的账号」。

你会看到：

- 新增账号
- 导入
- 刷新
- 平台筛选
- 类型筛选
- 分组筛选
- 账号列表

新手第一次点「新增账号」。

## 第 2 步：填写基础信息

<Screenshot src="/images/guide/real-account-create-modal.png" alt="Pixel API 添加账号弹窗截图，展示授权方式、账号名称、备注、共享模式、平台、账号类型和下一步按钮">
  <strong>第一次按这个弹窗从上到下填：</strong>账号名称写清楚，备注可选，共享模式先选私有，再选择真实平台和账号类型。
</Screenshot>

| 字段 | 第一次怎么填 | 说明 |
| --- | --- | --- |
| 账号名称 | `我的 OpenAI Plus 1` | 只给你自己识别 |
| 备注 | 可不填 | 可记录账号来源、到期日、用途 |
| 共享模式 | 私有 | 第一次先不要共享给别人 |
| 平台 | 按真实账号选择 | OpenAI、Anthropic、Gemini、Antigravity |
| 账号类型 | 按页面可选项 | 前台个人通常是 OAuth 类账号 |
| 账号等级 | 按真实等级 | OpenAI 需要区分 Free、Plus、Pro、Team |
| 代理 IP | 页面要求时选择 | Pro 或登录授权场景常用 |

## 第 3 步：完成授权或导入

根据平台不同，页面可能要求你：

1. 打开授权链接。
2. 登录官方账号。
3. 同意授权。
4. 复制回调内容。
5. 回到 Pixel API 粘贴并确认。

操作时注意：

- 浏览器里不要同时登录多个同平台账号。
- 授权前确认登录的是要接入的账号。
- 不要把别人的账号凭证粘进来。
- 页面提示代理 IP 时，不要跳过代理步骤。

## 第 4 步：添加成功后看列表

回到“我的账号”列表，检查：

| 项目 | 正常表现 |
| --- | --- |
| 账号名称 | 能看到刚才填写的名称 |
| 平台 | 和你选择的平台一致 |
| 模式 | 第一次应该是私有 |
| 状态 | 正常、可用或等待检测 |
| 错误信息 | 为空，或有明确可处理提示 |
| 可调度 | 不要被关闭 |

如果状态异常，不要继续添加更多账号。先处理这一个。

## 批量导入什么时候用

已经熟悉流程后再用「导入」。

导入适合：

- 多个 OAuth JSON 文件。
- 多个 Refresh Token。
- Claude Session Key。
- Gemini 或 Antigravity 官方 OAuth JSON。

导入细节见 [添加和导入账号](/docs/owner-add-account)。

## 成功标准

完成这一页后，你应该已经：

1. 在“我的账号”里看到新账号。
2. 账号平台和模式正确。
3. 没有明显错误信息。
4. 知道失败时先处理当前账号，而不是继续批量导入。

继续看 [测试私有自用](/docs/owner-test-private-account)。
