提现前先确认收益已经进了余额流水。还没到账的收益提不出来。

## 先上传收款码

进「个人资料」→「余额提现与收款码」。

<Screenshot src="/images/guide/real-profile-withdrawal.webp" alt="Pixel API 个人资料页面余额提现与收款码截图，展示当前余额、提现状态、提交提现、收款码管理和提现记录">
  <strong>提现入口就在这里：</strong>先上传保存收款码，再填提现金额，最后在提现记录看状态。
</Screenshot>

在「收款码管理」里选支付宝或微信，上传你的**真实静态收款码**图片，然后**点保存**，等页面提示"收款码已保存"。

要上传的是支付软件里保存的静态收款码，**不建议用临时截图的收款码**。图片格式支持 PNG、JPEG、GIF、WebP，不超过 1MB；格式不对或超大页面会直接报错。

<Callout type="warn" title="只上传不保存等于没换">
  换了新图片一定要点保存。只上传不保存，提交提现时可能仍然用旧收款码，或者直接提示未保存。
</Callout>

## 提交提现

在「提交提现」里输入金额、选收款方式、看清"本次扣除"、确认余额够，然后提交。

规则有四条：

- 最低提现 `1.00`。
- 金额最多两位小数。
- **首次提交额外扣 `0.10`**。
- 同一用户只能有一笔待结算提现。

所以第一次提 `1.00` 时，本次扣除是：

```text
1.00 + 0.10 = 1.10
```

**之后的提现不再收这笔手续费**，首次手续费显示为 `0`。

## 四种提现状态

| 状态 | 含义 |
| --- | --- |
| 待结算 | 已提交，等待处理。**这个状态可以取消，取消后金额退回余额** |
| 已结算 | 已处理完成 |
| 已取消 | 你取消了申请，金额已退回 |
| 已拒绝 | 管理员拒绝，按站点规则处理 |

## 提交失败的六种提示

| 提示 | 怎么办 |
| --- | --- |
| 请先上传并保存收款码 | 上传后点保存 |
| 新收款码需要先保存 | 点保存再提交 |
| 提现金额最低 1.00 | 填不少于 1.00 |
| 最多两位小数 | 别输三位以上小数 |
| 余额不足 | 降低金额或等收益到账 |
| 已有待结算提现 | 等它处理完，或先取消当前那笔 |

分成比例、结算口径等完整规则见[计费与提现](/docs/billing)。
