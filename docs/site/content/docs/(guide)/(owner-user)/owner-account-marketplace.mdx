---
title: 创建和管理账号广场房间
description: 用已有账号或 OAuth 新账号创建房间，再管理同平台、同等级的房间账号与共享策略。
---

账号广场现在按“房间”发布，不再把每个上游账号单独作为一个商品。号主先用一个账号创建房间，之后可以把同一号主、同平台、同等级的其他账号加入房间。普通用户选择的是房间，系统在房间内调度健康账号。

## 什么时候适合创建房间

适合：

- 至少有一个状态正常、可调度且等级已识别的 OpenAI 或 Anthropic OAuth 账号。
- 你愿意设置房间的席位、倍率、小时费、低消、最低余额和模型白名单。
- 你希望多个同等级账号共用一套展示、计费和用户席位规则。
- 你能定期检查房间内健康账号数、实时容量、用量窗口和收益流水。

不适合：

- 账号还未通过私有测试，或者状态、代理、等级仍不确定。
- 你想把不同平台、不同等级的账号混在一起。
- 你不想让其他用户占用共享席位。

## 第 1 步：进入账号广场并创建房间

进入「账号广场」，点击「创建房间」。

创建来源有两种：

| 来源 | 适用场景 | 会发生什么 |
| --- | --- | --- |
| 选择已有账号 | 页面提供的复用入口 | 目标是保留账号 ID、凭证、代理和账号并发，用它创建房间 |
| 登录新账号 | 账号尚未添加到平台 | 先完成 OAuth，再同时创建首个账号和房间 |

已有账号必须状态正常、可调度、等级已识别，而且尚未加入其他房间。私有账号可以直接创建房间；公共号池账号会先停止接收新请求并等待在途请求排空，然后在同一次创建操作中切换为平台账号模式。排空期间请不要重复提交。

<Callout title="三种对外模式互斥">
  一个账号同一时间只能处于「仅本人」「公共号池」或「平台账号模式」中的一种对外投放状态。进入房间后，它不会继续留在公共号池。
</Callout>

## 第 2 步：填写房间配置

创建房间时重点填写：

| 字段 | 含义 |
| --- | --- |
| 房间名称 | 同一号主下必须唯一，不能包含空格、换行或制表符 |
| 席位 | 同时激活使用房间的用户数，范围 2–12 |
| 单用户并发 | 每个使用者在房间中的并发上限 |
| 账号倍率 | 其他用户请求费用的倍率 |
| 小时费 | 其他用户激活占位后按分钟预扣 |
| 免小时费低消 | 核销窗口内请求消费达标后退回小时费；`0` 表示关闭 |
| 最低余额 | 其他用户加入前必须满足的余额门槛 |
| 模型白名单 | 房间允许调用的模型，至少保留一个 |
| 5h / 7d 保护 | 房间共享可使用的额度窗口比例 |

如果选择已有账号，代理和账号并发沿用该账号，不能在房间创建页修改。如果使用 OAuth 登录新账号，还需要选择代理并设置首个账号的并发。

房间总并发来自房间内所有有效成员账号并发之和，必须满足：

```text
房间总并发 >= 单用户并发 × 席位
```

例如席位为 3、单用户并发为 5，房间内有效账号的并发总和至少要达到 15。

更完整的取值和计费说明见[设置房间定价和限制](/docs/owner-pricing-limits)与[参数说明](/docs/owner-params)。

## 第 3 步：检查房间是否正常

创建成功后切到「我的」视图，确认：

1. 房间平台和账号等级正确。
2. 「健康账号」不是 `0 / 0`，并且状态为可用。
3. 房间总并发、席位、倍率、小时费和模型符合预期。
4. 5 小时 / 7 天可用量与保护比例正常。
5. 从普通用户视角能够看到并加入这个房间。

如果房间没有健康账号，普通用户无法正常激活使用。应先回到「我的账号」处理账号状态、代理、授权或调度问题。

## 第 4 步：给房间加入更多账号

在「我的」视图找到房间，点击「查看房间账号」，再切到「加入房间」。

候选账号必须同时满足：

- 属于当前号主。
- 与房间平台一致。
- 与房间账号等级一致，且等级不能是 `unknown`。
- 已在「我的账号」中切换为对应平台账号模式。
- 尚未加入其他房间。

可以多选后批量加入。服务端会逐个校验，因此批量操作可能出现部分成功、部分失败；页面会列出每个失败账号的原因。

<Callout title="先切账号模式，再加入房间">
  「加入房间」不会替你把私有或公共号池账号切成平台账号模式。先到「我的账号」把目标账号切换为对应平台账号模式，再回到房间批量加入。
</Callout>

## 第 5 步：移出房间账号

在「房间内账号」页选择账号并点击「退出房间」。

退出只解除账号与当前房间的关系：

- 不删除账号。
- 不改凭证、代理、分组或账号状态。
- 账号仍保持原平台账号模式。
- 最后一个账号退出后，房间会自动暂停。

账号有在途房间请求时，模式切换或移出可能需要等待请求排空。不要在用户高峰期频繁搬动账号。

## 第 6 步：编辑房间策略

「编辑配置」只修改房间级策略，例如房间名称、席位、倍率、单用户并发、小时费、最低余额和保护比例。成员账号的代理与账号并发必须回到「我的账号」逐个修改。

大部分房间配置在有活跃席位时会被锁定，避免用户按旧价格或旧限制继续使用。模型白名单有独立入口；修改后仍应观察实际请求是否成功。

## 成功标准

完成这一页后，你应该已经：

1. 使用已有账号或 OAuth 新账号建立了一个房间。
2. 理解用户选择的是房间，房间内可以包含多个同平台、同等级账号。
3. 知道如何批量加入、移出和排查房间成员账号。
4. 能区分房间级策略与账号级代理、并发配置。

继续看[设置房间定价和限制](/docs/owner-pricing-limits)，再到[查看收益流水](/docs/owner-check-income)核对真实结算。
