---
title: 设置定价和限制
description: 新手号主上架账号广场时，如何设置倍率、小时费、低消、席位、并发、最低余额、模型白名单和保护比例。
---

这一步的目标是：用保守参数上架，既别吓跑用户，也别让账号压力太大。

参数不是越高越赚钱。没人使用，收益就是 0；设置太激进，还可能带来失败率和风控风险。

## 推荐新手参数

第一次可以先这样填：

| 参数 | 建议 |
| --- | --- |
| 席位 | 2 或 3 |
| 账号并发 | 20 |
| 单用户并发 | 5 |
| 账号倍率 | 参考同类账号，不要明显高于市场 |
| 小时费 | 0.2 或更低 |
| 免小时费低消 | 不懂先 0 |
| 最低余额 | 低门槛，例如 1 |
| 模型白名单 | 只放确认可用模型 |
| 保护比例 | 先保持默认 |

## 席位怎么设

席位表示最多允许多少个用户同时占用你的账号。

新手建议：

```text
2 到 3 个
```

席位太少，账号可能经常满员；席位太多，账号压力会变大。

## 并发怎么设

有两个并发：

| 参数 | 含义 |
| --- | --- |
| 账号并发 | 这个账号整体最多同时处理多少请求 |
| 单用户并发 | 一个用户最多同时占多少请求 |

关系：

```text
账号并发 >= 单用户并发 × 席位
```

例如席位 3、单用户并发 5，账号并发至少 15。第一次用 20 通常比较稳。

## 倍率怎么设

倍率影响用户请求费用：

```text
用户请求费用 = 模型原始费用 × 账号倍率
```

建议：

1. 先参考同类账号。
2. 不要明显高于市场。
3. 账号稳定、模型稀缺时再考虑提高。
4. 没人用时先别急着调很多参数，先看价格和模型是否有吸引力。

## 小时费和低消怎么设

小时费用来防止用户长期占位不使用。

低消用来鼓励真实使用。用户在窗口内请求消费达标后，可能退回小时费。

新手建议：

- 小时费先低一些，例如 0.2 或更低。
- 不懂低消就先填 0。
- 如果发现用户占位不使用，再设置较低的免小时费低消。

## 最低余额怎么设

最低余额是用户加入前必须满足的账户余额。

设太高会挡住新用户；设太低可能用户刚加入就余额不足。

第一次建议保持低门槛，观察后再调整。

## 模型白名单怎么设

只放你确认可用的模型。

不要为了吸引用户写入不存在或不稳定的模型。模型不支持会导致用户请求失败。

如果你不确定模型名：

1. 查看账号实际支持模型。
2. 看可用渠道或 API 参考的模型列表。
3. 先少放几个常用模型。
4. 观察失败请求后再补充。

## 什么时候调参

不要一天改很多次。先观察：

1. 是否有人加入。
2. 是否经常满席。
3. 是否有大量失败请求。
4. 是否并发打满。
5. 是否有收益流水。
6. 用户是否加入后很快退出。

一次只改一个关键参数，例如只改小时费或只改倍率。这样才能判断哪个参数有效。
