号主用户是把自己的 OpenAI、Claude、Gemini、Antigravity 等账号接入 Pixel API 的用户。你可以只给自己用，也可以共享给其他用户使用并获得收益。

这篇先讲全流程。完全新手建议按左侧目录从 [准备账号](/docs/owner-prerequisites) 开始；具体添加账号看 [添加和导入账号](/docs/owner-add-account)，参数细节看 [参数说明](/docs/owner-params)。

## 号主能做什么

你可以选择三种使用方式：

| 方式 | 谁能用你的账号 | 是否产生号主收益 | 适合场景 |
| --- | --- | --- | --- |
| 私有模式 | 只有你自己 | 不产生共享收益 | 你想托管自己的账号，自己通过 API 用 |
| 公共模式 | 平台共享号池里的普通用户 | 产生共享账号收益 | 你的账号有闲置额度，希望自动进入共享池 |
| 账号模式 | 账号广场里主动加入你房间的用户 | 产生账号模式收益 | 你希望用房间统一定价、席位和模型，并管理同平台同等级账号 |

<Callout title="收益的前提是『别人在用』">
  自用自己的房间按站点全局自用倍率计费，不收小时费，也不产生号主或邀请者收益。只有其他用户使用你的房间时，才会产生共享收益。
</Callout>

## 从 0 到收益的完整路线

你要完成 9 个阶段：

<Steps>
  <Step>按 [准备账号](/docs/owner-prerequisites) 确认账号平台、等级、凭证、代理 IP 和风险边界。</Step>
  <Step>按 [添加第一个账号](/docs/owner-create-first-account) 在“我的账号”里新增或导入一个账号。</Step>
  <Step>按 [测试私有自用](/docs/owner-test-private-account) 先用私有模式跑通一条请求。</Step>
  <Step>按 [开启公共共享](/docs/owner-public-share) 把稳定账号切到公共模式并等待共享校验。</Step>
  <Step>如果想让用户主动选择你的共享方案，按 [创建和管理账号广场房间](/docs/owner-account-marketplace) 设置账号模式。</Step>
  <Step>按 [设置房间定价和限制](/docs/owner-pricing-limits) 配置倍率、小时费、低消、席位、并发和模型白名单。</Step>
  <Step>按 [查看收益流水](/docs/owner-check-income) 从使用记录和余额流水确认收益是否产生。</Step>
  <Step>按 [提现和收款码](/docs/owner-withdrawal-setup) 上传收款码并提交提现。</Step>
  <Step>遇到异常时按 [号主问题排查](/docs/owner-troubleshooting) 定位账号、代理、校验、收益或提现问题。</Step>
</Steps>

## 第 1 阶段：准备账号

先确认你的账号属于哪类：

| 平台 | 常见凭证 | 备注 |
| --- | --- | --- |
| OpenAI / ChatGPT / Codex | OAuth JSON、Refresh Token、账号登录授权 | Free/Plus/Team 可导入 JSON 或 Refresh Token；Pro 必须账号登录导入 |
| Claude / Anthropic | OAuth JSON、Claude Session Key | 个人导入会创建官方 OAuth 账号 |
| Gemini | 带 Gemini 平台信息的 OAuth JSON | 不接受普通 Token |
| Antigravity | 带 Antigravity 平台信息的 OAuth JSON | 不接受普通 Token |

不要把官方 API Key、URL、Upstream、Cookie 当作个人账号导入。前台个人导入会拒绝这类凭证。

## 第 2 阶段：添加账号

进入“我的账号”，你会看到：

- 新增账号
- 导入
- 刷新
- 批量操作
- 平台筛选
- 类型筛选
- 分组筛选

第一次建议：

1. 只添加 1 个账号。
2. 先选私有模式。
3. 测试能正常调用后，再切公共模式或创建账号广场房间。

这样排查最简单。

## 第 3 阶段：选择共享模式

### 私有模式

私有模式的意思是账号只给你自己调度，不进入公共共享号池。

适合：

- 你只是想把自己的账号变成 API 使用。
- 你还在测试账号是否稳定。
- 你不想让其他用户消耗这个账号。
- 账号敏感，不希望进入共享池。

私有模式不产生共享收益。

### 公共模式

公共模式的意思是账号通过校验后进入共享号池，供其他用户自动调度。

适合：

- 账号有闲置额度。
- 愿意让平台自动调度。
- 不想自己维护价格、席位、用户选择。
- 希望按站点公共共享分成获得收益。

切换为公共模式后，系统会进行公共共享校验。校验会检查账号测试、共享号池和分成策略是否可用。未通过时可能进入待审核或暂停状态。

### 账号模式

账号模式的意思是用户在“账号广场”主动选择你的房间，绑定到自己的账号模式 API Key；系统再在房间内调度健康成员账号。

适合：

- 你希望自己设置房间倍率、小时费、最低余额、席位。
- 你希望用户按模型、价格、账号等级和健康容量选择你的房间。
- 你能接受用户加入、预约、结束使用的席位逻辑。

账号模式不是简单的“公共开关”。它是“房间 + 成员账号池”：房间负责展示、价格和席位，成员账号负责实际请求能力。

## 第 4 阶段：测试账号

添加账号后，先看账号列表里的：

- 状态
- 错误信息
- 可调度开关
- 今日统计
- 额度快照
- 共享状态

如果账号状态异常，先不要切公共模式。先处理异常：

1. 刷新 token。
2. 重新授权。
3. 检查代理 IP。
4. 检查账号等级。
5. 降低并发。

只有账号稳定后，再共享给别人使用。

## 第 5 阶段：产生收益

收益来自其他用户实际使用你的账号。

常见收益类型：

| 类型 | 在余额流水里可能显示 |
| --- | --- |
| 公共共享号池收益 | 共享账号收益 |
| 账号广场收益 | 账号模式收益 |
| 邀请分成 | 邀请分成收益 |
| 专属分组佣金 | 专属分组佣金 |

公共号池和账号广场房间按站点当前全局共享分成策略结算。策略可以包含号主、符合条件的邀请者和平台三方比例，并只影响后续用量；具体比例以余额流水为准。

## 第 6 阶段：提现

当收益进入账户余额后，你可以继续站内消费，也可以申请提现。

提现规则：

- 最低提现金额 `1.00`。
- 金额最多保留两位小数。
- 首次提交提现申请额外扣除 `0.10`。
- 同一用户只能保留一笔待结算提现。
- 收款码支持支付宝和微信。
- 收款码图片必须是 PNG、JPEG、GIF 或 WebP。
- 收款码图片不能超过 1MB。
- 待结算申请可以取消，取消后金额退回余额。

详细操作见 [收益和提现](/docs/owner-income)。

## 新手号主推荐路线

如果你完全没经验，按这个路线最稳：

1. 先导入 1 个 OpenAI Plus 或 Claude 账号。
2. 选择私有模式。
3. 给自己创建一个私有分组 API Key。
4. 用 [ChatCompletions 格式](/docs/api/chat-completions) 或客户端发送一条测试消息。
5. 确认账号状态、用量记录和余额流水正常。
6. 再切公共模式，等待公共共享校验。
7. 公共模式稳定后，再考虑创建账号广场房间。
8. 创建房间时先使用保守参数：少量席位、较低小时费、明确模型白名单。
9. 观察 1 到 2 天收益和错误率。
10. 再逐步调倍率、席位、并发和低消。

<Callout type="warn" title="一次只做一件事">
  不要一开始批量导入很多账号、同时开公共模式、同时创建和扩充房间。那样一旦出问题，很难判断是凭证、代理、成员账号、并发、模型还是价格参数导致。
</Callout>
