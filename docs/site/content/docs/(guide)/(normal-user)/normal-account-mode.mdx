title: 使用账号广场
description: 在账号广场选择房间，理解房间调度、倍率、小时费、低消、预约与空闲退出，并绑定账号模式 API Key。
---

账号广场适合想自己选择共享方案的用户。普通共享号池由系统自动选池；账号广场则由你比较房间的模型、健康账号、容量、席位和价格，再把账号模式 API Key 绑定到一个房间。

房间可能包含多个同一号主、同平台、同等级的账号。你加入的是房间席位，不是永久锁死某个上游账号；系统会在房间内调度健康账号，当前成员不可用时也可以改绑到其他健康成员。

## 什么时候需要账号广场

以下情况再考虑账号广场：

- 想固定使用某个号主提供的一套房间能力。
- 想按模型白名单、账号等级、健康账号数和实时容量选择。
- 想自己比较倍率、小时费、最低余额和单用户并发。
- 想在房间满席时预约，并在后续请求时按顺序尝试接续。

## 账号广场怎么计费

| 费用 | 什么时候产生 | 怎么理解 |
| --- | --- | --- |
| 请求费用 | 真正发送模型请求时 | 按模型实际用量乘以房间倍率 |
| 小时费 | 激活占用房间席位时 | 按实际激活分钟预扣，预约等待期间不收 |

如果房间设置了“免小时费低消”，平台会按激活时长折算低消。单个核销窗口最长 1 小时，窗口结束时请求消费达标就退回该窗口已预扣的小时费。

示例：小时费 `0.60/小时`、低消 `0.30/小时`，实际激活 5 分钟。系统先预扣 `0.05`，对应低消是 `0.025`；请求消费达到 `0.025` 时退回 `0.05`，否则不退。

## 第 1 步：创建账号模式 API Key

进入「API 密钥」并创建一个只绑定账号模式分组的 Key：

| 字段 | OpenAI 房间 | Anthropic 房间 |
| --- | --- | --- |
| 分组 | `OpenAI账号模式` | `Anthropic账号模式` |
| 多分组路由 | 第一次使用先关闭 | 第一次使用先关闭 |

Key 的分组必须与房间平台一致。普通共享分组、私有分组或跨平台账号模式 Key 都不能加入该房间。

## 第 2 步：筛选和选择房间

进入「账号广场」，先切换 OpenAI 或 Anthropic，再按需要筛选和排序。

重点看房间卡片：

| 字段 | 意思 |
| --- | --- |
| 健康账号 | 房间内当前健康账号数 / 账号总数；健康数为 0 时不要加入 |
| 账号等级 | 房间内成员必须保持一致的账号等级 |
| 实时容量 | 房间内账号当前并发占用情况 |
| 席位 | 当前激活用户数 / 可激活用户总数 |
| 账号并发 | 房间内有效账号并发总和 |
| 单用户并发 | 你在这个房间里的并发上限 |
| 倍率、小时费、低消 | 请求计费与席位占用成本 |
| 最低余额 | 非号主用户加入前必须达到的余额 |
| 可用模型 | 房间允许调度的模型白名单 |

不要只看倍率。健康账号少、实时容量紧张或小时费高的房间，即使倍率低也不一定适合短时间轻量使用。

## 第 3 步：优先用选号助手

不知道怎么选时，点击「选号助手」，选择账号模式 Key 和实际模型，再填写预计请求次数、使用时长和 Token 用量。也可以使用轻量、均衡、重度或近 3 天均值预设。

结果会综合：

- 房间倍率、小时费与低消。
- 健康账号、席位与并发容量。
- 模型白名单和额度窗口。
- 预计请求成本、小时费与准入金额。

选号助手只做当前条件下的估算，实际费用仍以真实请求、激活时长和最终流水为准。

## 第 4 步：设置空闲退出

加入前设置“空闲退出”，默认通常是 10 分钟：

- 必须是 1–10080 的整数分钟，不能填 0。
- 从最后一次请求结束后开始计算。
- 连续空闲达到设定时间会自动退出并停止占位。
- 预约项会保存这个设置，真正激活后才开始生效。

短时使用建议保持较小值；持续工作可以适当提高，但会增加忘记占位的成本。

## 第 5 步：加入或预约

在房间卡片选择同平台账号模式 Key，点击「加入使用」，再在确认弹窗核对价格、模型、容量、绑定 Key 和空闲退出时间。

| 结果 | 含义 |
| --- | --- |
| 已加入使用 | 已激活房间席位，可以立即发请求 |
| 已加入预约列表 | 房间当前满席，预约等待期间不收小时费 |

每个账号模式 Key 最多保留 5 个房间预约。预约不会因为你一直停留在页面就自动激活；下一次使用这个 Key 发出 API 请求时，系统才会按预约顺序尝试激活。

## 第 6 步：用绑定的 Key 发请求

把这个账号模式 Key 配到客户端，并使用房间白名单内的模型。请求模型不在白名单时不会进入房间。

请求后建议检查：

1. 「使用记录」中的 Key、分组、模型和请求费用。
2. 账号广场「我的消费」中的本次使用、今日或 7 天汇总。
3. 余额流水里的小时费预扣、普通退回或低消达标退回。
4. 当前房间状态与低消进度。

## 第 7 步：管理预约和结束使用

- 正在使用：点击「结束使用」，绑定会立即解除，后续请求会提示账号模式分组未绑定。
- 预约中：点击「移出预约」，不再参与后续激活。
- 有多个预约：可以按 Key 查看并调整预约顺序。

不要只依赖空闲退出。不再使用时主动结束，费用和绑定状态最清楚。

实际产生过请求的使用记录可以在结束后评分；留言可能需要先通过平台审核。号主不能评价自己的房间。

## 号主使用自己的房间

号主可以把账号模式 Key 绑定到自己的房间。自用请求按站点当前配置的全局自用倍率计费，不收小时费、不校验最低余额、不占共享席位，也不产生号主或邀请者收益。

页面确认弹窗会显示实时自用倍率；不要把文档里的历史示例值当成固定费率。
