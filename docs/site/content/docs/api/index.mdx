## 认证方式

```http
Authorization: Bearer sk-user-key
```

<Callout type="warn" title="只使用控制台的 API 密钥">
  这个 Key 来自控制台「API 密钥」。不要把登录 JWT、管理员密钥或账号 token 填到这里。
</Callout>

## 调用规则

1. 接口页中的 `Send` 只用于验证模型接口连通性，API Key 不会写入文档站存储。
2. 选择模型前，优先用 [列出模型](/docs/api/models) 或 [列出 Gemini 模型](/docs/api/gemini-models) 查询当前 Key 可访问模型。
3. `Images` 接口只支持 OpenAI 平台分组；其他平台分组会返回不支持。
4. Gemini 原生接口使用 `/v1beta` 前缀，路径中的 `{model}` 要替换为实际模型名。
5. Antigravity 专用接口会强制走 Antigravity 账号，不与普通分组混合调度。

## 阅读顺序

如果你是第一次接入：

1. 先看 [ChatCompletions 格式](/docs/api/chat-completions)，这是最常见的 OpenAI 兼容调用。
2. 使用 Codex 或新版客户端时，再看 [Responses 格式](/docs/api/responses)。
3. 使用 Claude Code 时，看 [原生 Claude 格式](/docs/api/claude-messages)。
4. 使用 Gemini CLI 或 SDK 时，看 [Gemini 文本聊天](/docs/api/gemini-generate-content)。
5. 模型名报错时，看 [列出模型](/docs/api/models)。

## 最小测试

```bash
curl -X POST "https://ai-pixel.online/v1/chat/completions" \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      { "role": "user", "content": "你好，请只回复：Pixel API 已连接" }
    ]
  }'
```

收到模型回复后，再回到控制台“使用记录”确认请求、模型、分组和消耗是否符合预期。
